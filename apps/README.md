# apps

Settings and helpers for the apps I use. Nothing here is installed by `install.sh`.

- `vesktop/vencord-settings.json` — Vencord plugins and theme (copy the keys by hand, see the main README).
- `vesktop/omacord` — recolours Vesktop / Discord in the Omarchy theme (ASwenia/omacord, MIT), kept for the theme hooks to come.
- `steam/omasteam`, `telegram/omatele` — my Steam (Millennium) and Telegram Desktop palettes that follow the Omarchy theme (MIT), kept for the same hooks.
