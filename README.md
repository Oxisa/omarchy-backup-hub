# omarchy-backup-hub

Личные плагины, хуки и настройки приложений для Omarchy.

## Установка

```bash
git clone https://github.com/Oxisa/omarchy-backup-hub.git ~/.local/opt/omarchy-backup-hub
~/.local/opt/omarchy-backup-hub/install.sh
```

`install.sh` делает следующее:

1. Ставит недостающие пакеты: `jq`, `curl`, `yt-dlp`, `ffmpeg`, `wl-clipboard`, `brave-bin` и `chromium`. Если не установлен Happ, выводит подсказку.
2. Делает Brave браузером по умолчанию, см. [Туннель и браузеры](#туннель-и-браузеры).
3. Создаёт симлинки на содержимое `omarchy/plugins/` и `omarchy/hooks/theme-set.d/` в `~/.config/omarchy/`, а на команды из `omarchy/bin/` — в `~/.local/bin/`. Если на месте симлинка уже лежит обычный файл, он сохраняется как `*.pre-hub.bak`.
4. Включает плагины из `omarchy/plugins/` и добавляет пункты меню из `omarchy/menu/` в `~/.config/omarchy/extensions/omarchy-menu.jsonc`. Пункты вставляются между метками `omarchy-backup-hub-menu-start/end`, остальное в файле не трогается.
5. Удаляет и устанавливает веб-приложения из раздела [Web-apps](#web-apps) и назначает каждому браузер по колонке «Маршрут». Списки продублированы в начале `install.sh`, при изменении правьте оба места.
6. Один раз запускает хуки смены темы, чтобы они применились сразу.

Скрипт можно запускать повторно: уже установленные пакеты, включённые плагины и веб-приложения он пропускает. Вручную остаются Happ и его настройка обхода (см. [Туннель и браузеры](#туннель-и-браузеры)) и настройки Vesktop (см. [Vesktop](#vesktop)).

## Структура

| Путь | Что внутри | Куда ставится |
|---|---|---|
| `omarchy/plugins/` | Плагины omarchy-shell | `~/.config/omarchy/plugins/` |
| `omarchy/hooks/theme-set.d/` | Хуки `omarchy theme set` | `~/.config/omarchy/hooks/theme-set.d/` |
| `omarchy/bin/` | Команды хаба | `~/.local/bin/` |
| `omarchy/menu/` | Пункты меню Omarchy | `~/.config/omarchy/extensions/omarchy-menu.jsonc` |
| `apps/<программа>/` | Настройки отдельных программ | вручную, см. ниже |

## Web-apps

### Удалить

Стандартные веб-приложения Omarchy, которые не нужны (X и YouTube остаются):

```bash
for app in "Basecamp" "Discord" "Google Contacts" "Google Maps" "Google Messages" \
           "Google Photos" "HEY" "WhatsApp" "Zoom"; do
  omarchy-webapp-remove "$app"
done
```

## Туннель и браузеры

Туннель работает через [Happ](https://happ.su) в режиме TUN и пропускает через прокси весь трафик системы. Российские сайты через прокси работают плохо или не работают вовсе, поэтому браузеры разделены:

| Браузер | Для чего | Трафик |
|---|---|---|
| Brave | Личный браузер (по умолчанию) и веб-приложения с маршрутом «туннель» | через туннель |
| Chromium | Только веб-приложения с маршрутом «напрямую» | мимо туннеля |

Разделение держится на настройке Happ, её нужно сделать вручную один раз:

1. Установите Happ с [happ.su](https://happ.su): в репозиториях и AUR его нет.
2. В Happ откройте **настройки → TUN → Per-App Proxy**, включите режим обхода и добавьте Chromium (`/usr/lib/chromium/chromium`).

Проверить настройку можно так: в `~/.config/Happ/config.json` среди правил маршрутизации должно быть правило `"outbound": "direct"` с путём к Chromium.

## SoundHub

Плагин `osia.soundhub`: один центр звука вместо нескольких аудиоплагинов. Сейчас готов этап 1.

- **В панели:** маленькая пластинка, которая крутится во время музыки, и живой спектр. ЛКМ — окно, ПКМ — пауза, средняя кнопка — следующий трек, колёсико — громкость.
- **Сейчас играет:** обложка и пластинка с тонармом (тонарм идёт по дорожке вместе с треком), перемотка, управление, громкость плеера, спектр, выбор источника. Работает с любым MPRIS-плеером.
- **Микшер** (вместо вкладки «Звук», по мотивам Logitech Mixline): источники (приложения и микрофоны), миксы и выходы. Источник подключается к миксу кликом по чипу микса; в карточке микса — громкость каждого входа, выключение и отключение, выбор устройства (устройство, через эквалайзер или «только виртуально» для OBS/Discord) и мониторинг. Активный выход помечен «ЗВУК ЗДЕСЬ» с переключателем эквалайзера, используемый микрофон — «МИКРОФОН СЕЙЧАС». **Пресеты** (вкладки сверху) хранят всю конфигурацию: миксы, кабели, выход с эквалайзером и микрофон; у каждого пресета свои сворачиваемые **папки** устройств. Отключённые устройства, на которые что-то ссылается, остаются в списке серыми, а миксы сами возвращаются на устройство, когда оно снова подключено. Миксы — настоящие виртуальные устройства (`soundhub-mixes.service`), маршруты держит `soundhub-mixd.service`; бэкенд — `bin/soundhub-mix`, состояние — `~/.config/soundhub/mixer.json`.
- **Эквалайзер:** 6 полос, пресеты, предусиление (авто или вручную). Работает отдельным процессом PipeWire под пользовательской службой `soundhub-eq.service` и меняется на лету, без перезапуска WirePlumber. Бэкенд — `omarchy/plugins/osia.soundhub/bin/soundhub-eq`, состояние хранится в `~/.config/soundhub/eq.json`.
- **Настройки:** язык (английский по умолчанию, русский), вид пластинки, стиль спектра, спектр в панели, уведомление о смене трека.
- **Прогресс трека** (на вкладке, в мини-плеере и виджете): «Змейка» — пройденная часть волной, которая течёт, пока играет (по умолчанию), «Волна» — столбики, «Линия». Выбор в настройках. Если плеер не сообщает длину трека (бывает у видео в браузере), по полосе бегает кусочек — видно, что идёт воспроизведение.
- **Виджет на рабочем столе:** карточка «Сейчас играет» под окнами (обложка или пластинка, волна с перемоткой, кнопки), видна только пока играет трек. В настройках: включение, монитор, положение (углы, стороны, центр — сетка 3×3) и прозрачность фона.

Зависимости: PipeWire и cava. Цвета берутся из темы Omarchy.

IPC: `qs -p /usr/share/omarchy/shell ipc call osia.soundhub <toggle|playing|sound|equalizer|settings>`.

Также есть «Сейчас играет» с текстами песен (LRCLIB) и «Фокус» (фоновые звуки, движок из OmaFocus). Дальше: библиотека локальной музыки, AirPlay, виджет на рабочий стол.

## Цитата дня

Плагин `osia.dailyquote` показывает цитату на рабочем столе, под окнами. Сверху — оригинал на своём языке (латиница готическим шрифтом UnifrakturMaguntia, OFL; японский, китайский и корейский — Noto Serif CJK; остальное — Noto Serif), под ним — перевод на язык из настроек (русский или английский) и автор. Если оригинал уже на этом языке, перевода нет.

- **Откуда цитаты:** примерно половина — из встроенной базы `quotes.json` (130 цитат на 12 языках: английский, японский, латынь, французский, немецкий, китайский, корейский, русский, греческий, испанский, итальянский, португальский — с ручным переводом), остальное — с сайтов ZenQuotes (цитата дня раз в сутки и случайные) и DummyJSON (религиозных авторов плагин пропускает). Цитаты с сайтов переводит MyMemory, если не вышло — Google; переводы и скачанные цитаты сохраняются в `~/.cache/dailyquote/pool.json` и идут в ход офлайн.
- **Настройки** открываются значком на панели: показ, размер, фон, положение (сетка 3×3 — углы, стороны, центр — или перетаскивание мышкой), «Сбросить» (положение, размер и фон по умолчанию), как часто менять цитату, новая цитата сразу и язык (панели и перевода).
- **Устройство:** скрипт `bin/dailyquote` хранит текущую цитату в `~/.local/state/omarchy/dailyquote/`, поэтому перезапуск оболочки её не меняет.
- **Основа:** надпись и панель переделаны из [quran-motivation](https://github.com/r4y-br/omarchy-quran-motivation) (MIT).

## TheNotch

«Чёлка» в стиле Dynamic Island живёт в отдельном репозитории: [Oxisa/TheNotch](https://github.com/Oxisa/TheNotch). Её дашборд SoundHub берёт страницы из `osia.soundhub` этого репозитория, поэтому ставьте её после `install.sh`:

```bash
omarchy plugin add https://github.com/Oxisa/TheNotch.git --enable
```

## Приложения

### Obsidian

Хук `omarchy/hooks/theme-set.d/obsidian-minimal` добавляет в тему Minimal (kepano) цветовую схему **Omasidian** в цветах текущей темы Omarchy. Обрабатываются хранилища из `~/.config/obsidian/obsidian.json`, у которых выбрана тема Minimal. Для каждого такого хранилища хук:

- пишет сниппет `.obsidian/snippets/omasidian.css` и обновляет его при каждой смене темы;
- один раз включает этот сниппет в `appearance.json`. Если потом выключить его вручную, хук не включит его обратно;
- добавляет пункт «Omasidian» в списки «Light/Dark mode color scheme» плагина Minimal Theme Settings.

Схема выбирается в настройках плагина Minimal Theme Settings. Пункт появится в списке после перезапуска Obsidian. Обновление плагина убирает пункт из списка до следующей смены темы Omarchy, но уже выбранная схема продолжает работать.

### Vesktop

- Тему refact0r/system24 под цвета текущей темы Omarchy настраивает хук `omarchy/hooks/theme-set.d/system24`. Он ставится через `install.sh`.
- В `apps/vesktop/vencord-settings.json` лежат включённые плагины Vencord и тема. Переносите только ключи `useQuickCss`, `themeLinks`, `enabledThemes` и `plugins` в `~/.config/vesktop/settings/settings.json`. Целиком файл не заменяйте: в нём хранятся сессии.
